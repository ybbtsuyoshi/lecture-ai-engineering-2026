# 第2回 解答

## 演習

- 使ったモデル・設定（result.json の config から）：
  モデルは Qwen/Qwen3.5-0.8B で、LoRA で追加学習した。基準設定は num_train_epochs=20、lr=2e-4、lora_r=16、lora_alpha=32、warmup_steps=6、max_seq_len=512、max_new_tokens=96、seed=42。生成は貪欲生成（do_sample=false）とし、学習前後を同じ条件で比べた。Google Colab の T4 で実行した。
- 自分で学習を実行したか（executed_training_myself）：
  はい（true）。基準条件ではセクション0〜7を実行した。設定を変えた6回では、毎回セクション1〜5を実行し、学習後の評価まで確認した。セクション8の4bit量子化は実行していない。
- 学習前：format_rate = 0.095（2/21） / content_rate = 0.0（0/21）
- 学習後：format_rate = 1.0（21/21） / content_rate = 0.905（19/21）
  ※学習後は基準条件（20周）の結果。
- 退行した質問：
  学習前との比較ではなし。ただし、5周と20周を比べると、15番「成績はいつ出ますか」と20番「オフィスアワーは事前予約が必要ですか」は、5周では正解し、20周では不正解になった。
- 学習後に残った失敗と、その型（根拠なしの質問に断定した / 根拠ありの質問に確認要求で逃げた ）：
  基準条件で残った失敗は2問で、どちらも「根拠なしの質問に断定した」型である。15番は成績の公開時期を聞かれたのに課題の提出期限を答え、20番は予約の要否を聞かれたのに受付の曜日と時間を答えた。どちらも FAQ に答えがないのに needs_review=false とした。FAQ にある別の答えを、言葉の近い質問に当てはめたと考えられる。「根拠ありの質問に確認要求で逃げた」型と、形式の崩れはなかった。
- 知識を問う質問（セクション6）の結果（学習前の分類 → 学習後の分類）と気づいたこと：

  | 質問 | 学習前の分類 → 学習後の分類 |
  |---|---|
  | この講座の最終課題の締切はいつですか | format_error → asserted |
  | 担当教員の名前は何ですか | format_error → needs_review |
  | 次回の講義のテーマは何ですか | format_error → needs_review |
  | 課題の提出期限はいつですか | format_error → asserted |

  学習前は4問とも needs_review の項目がなく、形式エラーになった。学習後は4問とも指定の形式で答え、教員名と次回のテーマについては確認を求めるようになった。

  一方、「最終課題の締切」には、FAQ にある一般の課題の提出期限を答えた（asserted）。この期限が最終課題にも当てはまるかは FAQ からは分からず、確認が必要な質問である。asserted は「断定した」という分類であり、答えの正しさを保証するものではない。これは本評価の15番・20番と同じく、言葉の近い FAQ の答えを当てはめる失敗である。

  なお、最後の質問はセル内のコメントでは「FAQ にある（対照）」とされているが、表の「FAQにある」は False と表示された。原因は確かめていないため、この表示だけで判断せず、FAQ 本文と判定の処理を確認する必要がある。
- 学習で変わったこと・変わらなかったこと：
  変わったのは形式と内容で、形式遵守率は 9.5% から 100% に、内容正解率は 0% から 90.5% に上がった。FAQ に情報がない質問のうち16〜19番の4問では、確認を求めるようになった。

  変わらなかったのは、関連する情報があるときに、その情報で質問に答えられるかを判断する点である。20周から40周に増やしても、誤答した15番・20番とその答えの文は一字一句同じだった。

## 宿題

- 取り組んだレベル：
  実装（基礎の内容も実施）。用意されたコードを実行したうえで、設定を1つずつ変える比較実験を6条件で行った。発展（セクション8の4bit量子化）は実施していない。
- 変えた設定やデータ：
  基準の「20周・学習率 2e-4・lora_r=16」から、次の設定を1項目ずつ変更した。ほかの設定は基準のままとし、学習データは変えず、評価は同じ21問で行った。
  - 周回数：5周、40周
  - 学習率：2e-5、1e-3
  - lora_r：4、64
- 結果（比較表や数字）：

  | 条件 | 形式遵守率 | 内容正解率 | 内容が×の問 | 学習時間 | 最後の Training Loss |
  |---|---|---|---|---|---|
  | 学習前 | 9.5% | 0%（0/21） | 21問すべて | ― | ― |
  | 5周 | 100% | 76.2%（16/21） | 6・10・16・18・19 | 53秒 | 1.5728 |
  | 20周・基準 | 100% | 90.5%（19/21） | 15・20 | 221秒 | 0.0137 |
  | 40周 | 100% | 90.5%（19/21） | 15・20 | 457秒 | 0.0111 |
  | 20周・学習率 2e-5 | 100% | 76.2%（16/21） | 6・16・17・18・19 | 228秒 | 1.0744 |
  | 20周・学習率 1e-3 | 100% | 90.5%（19/21） | 6・20 | 221秒 | 0.0117 |
  | 20周・r=4 | 100% | 90.5%（19/21） | 15・20 | 223秒 | 0.0132 |
  | 20周・r=64 | 100% | 85.7%（18/21） | 6・15・20 | 315秒 | 0.0168 |

  - 周回数：5周から20周で正解率は 76.2% から 90.5% に上がった。40周にすると学習時間は約2倍になり、Training Loss も 0.0137 から 0.0111 に下がったが、正解率も誤答の問も変わらなかった。Training Loss が下がっても、評価問題の正解率が上がるとは限らないことが分かった。なお5周は全10ステップのうち6ステップがウォームアップで、学習率が上がりきる前に学習が終わっている。
  - 学習率：2e-5 では Training Loss が 1.0744 までしか下がらず、正解率は 76.2% にとどまった。特に17番・18番では、FAQ にない内容を断定した。1e-3 は基準と同じ正解数だったが、誤る問題が15番から6番に変わった。
  - lora_r：r=4 では、学習するパラメータの割合を基準の約4分の1（0.84% → 0.21%）に減らしても同じ正解率だった。r=64 では学習時間が約1.4倍になり、正解率は 85.7% に下がった。ただし lora_alpha=32 を固定しているため、r を変えると変更の反映倍率である alpha÷r も変わる（基準 2、r=4 で 8、r=64 で 0.5）。結果を r の大きさだけで説明することはできない。
- ファインチューニングが向く場面・向かない場面についての考察：
  すべての学習条件で形式遵守率が100%になった。最も短い5周（10ステップ）でも同じだったことから、決まった出力形式や回答の方針を身につけさせる場面には、短い学習でも有効だと考える。FAQ に沿った回答の正解率も大きく改善した。

  一方、FAQ に答えがない質問への断定や、言葉の近い別の答えへの取り違えは、どの条件でも少なくとも1問残った。周回数・学習率・lora_r のどれを変えても、誤る問題の組み合わせが入れ替わるだけで、21問すべてに正解する条件はなかった。Qwen3.5-0.8B は、質問の言葉が FAQ の答えの言葉と近いと、その答えに引きずられて回答することがある。このため、正確な事実や回答できる範囲の判断を、ファインチューニングだけで保証することは難しいと考える。学習回数やパラメータ数を増やすだけでは改善せず、学習データの内容が重要である。

  今後は、関連情報と回答できるかの区別を学べる例（似た言葉を含むが FAQ に答えがない質問など）を学習データに加え、学習に使っていない質問で評価したい。また、形式・回答できるかの判断・内容の正しさを分けて確認したい。
